Daily Report Bot 🤖

A Python automation bot built using PyAutoGUI for the Gen AI Architect Program – Assignment 1.

What it does

Opens Google Chrome and visits a public website.

Fetches important information from the webpage.

Opens Microsoft Excel.

Adds the current date & time, fetched data, and a comment.

Saves the report as daily_report_YYYY-MM-DD.xlsx.

Takes a screenshot of the final Excel sheet.

Technologies

Python

PyAutoGUI

Google Chrome

Microsoft Excel

How to Run
pip install pyautogui
python daily_report_bot.py


⚠️ Do not move the mouse or type while the bot is running.

Output

📊 Excel report with the daily status.

📸 Screenshot of the completed Excel sheet.
